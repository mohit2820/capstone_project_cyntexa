# 🚀 Cyntexa Capstone Project

This project is a **Data Engineering project built using Databricks**.

It demonstrates how to build a simple data pipeline using **Bronze, Silver, and Gold layers** and create useful business insights from the data. 📊

## 🛠️ Tech Stack

* ☁️ Databricks
* ⚡ Apache Spark
* 🐍 Python
* 🗄️ SQL
* 📊 Databricks Dashboards
* 🔄 Databricks Asset Bundles

## 🏗️ Project Structure

```text
capstone_bundle/
│
├── src/          # Main project code
├── fixtures/     # Sample/test data
├── resources/    # Databricks resources
├── tests/        # Test files
├── databricks.yml
└── pyproject.toml
```

## 🔄 Data Pipeline

```text
Raw Data
   ↓
🥉 Bronze Layer
   ↓
🥈 Silver Layer
   ↓
🥇 Gold Layer
   ↓
📊 KPIs & Dashboards
```

### 🥉 Bronze Layer

Stores the raw data with minimal changes.

### 🥈 Silver Layer

Cleans and prepares the data for analysis.

### 🥇 Gold Layer

Creates business KPIs and analytics such as:

* 💰 Sales Performance
* 👥 Customer Analytics
* 📦 Product Insights
* 📈 Business KPIs

## 🎯 Project Goal

The main goal of this project is to practice **real-world data engineering concepts** using Databricks and build a clean analytics pipeline from raw data to dashboards. 🚀
